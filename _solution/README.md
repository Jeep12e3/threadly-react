# 🔑 _solution — Kunci Jawaban Sesi 2 (Hooks)

Folder ini **BUKAN bagian dari aplikasi** (tidak di-import ke mana pun).
Isinya versi LENGKAP dari file yang sengaja "dikosongkan" di project untuk latihan.

Gunakan folder ini untuk:
- Mentor: cek jawaban peserta.
- Peserta: kalau benar-benar stuck, intip di sini.

| File solution | Pasangannya di project | Konsep |
|---|---|---|
| `App.solution.jsx` | `src/App.jsx` | `useEffect` → `document.title` |
| `PostComposer.solution.jsx` | `src/components/PostComposer.jsx` | `useRef` (auto-focus) + `useEffect` (draft localStorage) |
| `LoginPage.solution.jsx` | `src/pages/LoginPage.jsx` | `useRef` + `useEffect` (auto-focus) |
| `useLocalStorage.solution.js` | (bonus, take-home) | Custom Hook |

## Cara "reset" ke versi kosong / jawaban
- Versi **kosong (latihan)** = yang ada di `src/`, ada penanda `// TODO (Sesi 2)`.
- Versi **jawaban** = file di folder ini.

Kalau mau langsung pakai versi jawaban, copy isi file `.solution.jsx` ke file aslinya.
